### What I'm Building

**[CIR — Confidential Inference Runtime](https://github.com/OluwaseunOlajide/CIR-POC)**
Hardware-attested, constant-time AI inference inside Trusted Execution Environments. CIR eliminates timing side-channels during model inference and produces cryptographic proof of execution integrity — so clients can verify *how* their data was processed, not just trust that it was.

Stack: Rust · Intel SGX · Gramine · Python · ONNX
